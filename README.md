# slot-machine-python
Meu primeiro projeto em Python: um jogo de caça-níqueis com interface gráfica e sons.
Este é o meu primeiro projeto em Python, e nele consegui conciliar diversos elementos de programação, como:

Interface gráfica com Tkinter para criar uma experiência visual interativa.

Threading para tocar sons sem travar a interface.

Uso de listas, dicionários e variáveis globais para controlar símbolos, fichas e vitórias.

Randomização para criar o efeito de giro da máquina de caça-níqueis.

Efeitos visuais e sons para deixar o jogo mais dinâmico e divertido.

O jogo permite girar a máquina, ganhar fichas ao conseguir combinações de símbolos iguais e reiniciar a partida quando desejar. É um projeto simples, mas que mostra como é possível integrar vários conceitos de programação em uma aplicação divertida.
